# Claude rule loader

For Stata, Python, or Julia code, the canonical coding standard is the root
file [`General Code Conventions.md`](../../General%20Code%20Conventions.md).
Read that file before writing or reviewing code in those languages. Its R
section only points back to
[`R Code Conventions.md`](../../R%20Code%20Conventions.md), which stays the
canonical standard for R — read that one directly for R work instead.

This file is intentionally only a loader so Claude's `.claude/rules/`
mechanism continues to find the repository standard without maintaining a
second copy.
