# Repository instructions

Read `R Code Conventions.md` before writing or reviewing R code. It is the
single canonical R coding standard for this repository.

Read `General Code Conventions.md` before writing or reviewing Stata, Python,
or Julia code. Its R section routes back to the canonical R standard.

Use the role-specific skill under `.agents/skills/` when the task matches one.
Skills define workflow and output behavior; they do not replace the canonical
coding standards.
